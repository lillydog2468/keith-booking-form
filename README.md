# Keith's booking form (GitHub trial)

This is a trial copy of the beading-tour booking form, so we can host and edit it from GitHub.

The live site is still [bookingkeith.netlify.app](https://bookingkeith.netlify.app/booking-form.html). Nothing here changes that until Keith says so.

## How we try changes

Ron’s way: do not edit the live copy directly.

1. Make a **new branch** from `main` (this first look is on `trial`).
2. Change the files on that branch.
3. Open it on GitHub Pages and check it works.
4. Only **merge to `main`** when Keith is happy.

The bookings themselves stay in Supabase. These pages are just the form.
